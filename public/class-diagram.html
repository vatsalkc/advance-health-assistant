Classes in the System:

+ userID: String
+ name: String
+ email: String
+ password: String
+ login()
+ logout()

Patient

+ healthHistory: String
+ enterSymptoms()
+ bookAppointment()
+ viewHistory()
+ addMedicineReminder()

Doctor

+ specialization: String
+ availability: String
+ updateAvailability()
+ viewPatientDetails()

Admin

+ manageUsers()
+ manageDataset()
+ monitorSystem()

Medicine

+ medName: String
+ dosage: String
+ setReminder()

Appointment

+ appointmentID: String
+ dateTime: DateTime
+ status: String
+ cancel()

MLEngine

+ predictDisease(symptoms)
+ recommendSpecialization()

SymptomDataset

+ dataPoints: List
+ updateData()

Relationships:
  • User (abstract) is inherited by Patient, Doctor, and Admin
  • Patient manages Medicine (1 to many)
  • Patient books Appointment (1 to many)
  • Doctor attends Appointment (1 to many)
  • Admin maintains SymptomDataset (1 to 1)
  • MLEngine processes SymptomDataset (dashed dependency)
