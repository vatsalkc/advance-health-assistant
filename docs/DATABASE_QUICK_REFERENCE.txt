================================================================================
DATABASE INDEXES
================================================================================

Performance indexes for frequently queried columns:

1. idx_doctors_auth_id (doctors.auth_id)
   - Fast doctor authentication lookup

2. idx_doctors_specialization (doctors.specialization)
   - Filter doctors by specialty

3. idx_appointments_doctor_id (appointments.doctor_id)
   - Doctor's appointment queries

4. idx_appointments_user_id (appointments.user_id)
   - User's appointment queries

5. idx_appointments_status (appointments.status)
   - Filter by appointment status

6. idx_medical_reports_patient_id (medical_reports.patient_id)
   - Patient's reports lookup

7. idx_medical_reports_doctor_id (medical_reports.doctor_id)
   - Doctor's reports lookup

8. idx_prescriptions_patient_id (prescriptions.patient_id)
   - Patient's prescriptions lookup

9. idx_prescriptions_doctor_id (prescriptions.doctor_id)
   - Doctor's prescriptions lookup
