========================================
CARDINALITY NOTATION EXPLAINED:
========================================

1       = Exactly one
0..1    = Zero or one
0..*    = Zero or many (also written as *)
1..*    = One or many
m..n    = Between m and n

In this diagram:
- Patient "1" -- "0..*" Medicine
  (1 Patient can have 0 or many Medicines)

- Patient "1" -- "0..*" Appointment
  (1 Patient can book 0 or many Appointments)

- Doctor "1" -- "0..*" Appointment
  (1 Doctor can attend 0 or many Appointments)

- Doctor "0..*" -- "0..*" Patient
  (Many Doctors can treat many Patients - Many-to-Many)

- Admin "1" -- "0..*" Patient
  (1 Admin can manage many Patients)

- Admin "1" -- "0..*" Doctor
  (1 Admin can manage many Doctors)

- Admin "1" -- "1" SymptomDataset
  (1 Admin maintains exactly 1 SymptomDataset)

- MLEngine "1" ..> "1" SymptomDataset
  (1 MLEngine processes 1 SymptomDataset)
  (Dashed line = dependency relationship)
